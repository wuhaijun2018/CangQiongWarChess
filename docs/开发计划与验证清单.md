## ✅ Phase 1：核心框架（2-4周）

### 目标
完成可运行的战棋战斗原型，验证核心玩法。

### 里程碑

| 周次 | 目标 | 验证标准 |
|------|------|---------|
| W1 | Unity 项目搭建 + Git | 项目可 clone，CI 可跑 |
| W2 | 战棋地图系统 | 格子可显示，可点击选中等 |
| W3 | 回合制框架 | 角色可移动、可攻击、AI 回合 |
| W4 | 五行相克系统 | 火>金>木>土>水>火 伤害修正生效 |

### 功能模块

- [ ] **BattleManager** — 回合制状态机（我方回合→敌方回合→结算）
- [ ] **TileMap** — 战棋格子（6×8 最小验证地图）
- [ ] **Unit** — 角色基础属性（HP/MP/ATK/MDF/SPD）
- [ ] **FiveElements** — 五行属性与相克修正
- [ ] **MoveRange** — 移动范围计算（A* / BFS）
- [ ] **AttackRange** — 技能/普攻范围计算
- [ ] **AI_Normal** — 简单 AI（随机攻击）
- [ ] **CI 验证** — GitHub Actions 可乐见构建产物

### 验证检查点

```markdown
## Phase 1 验证标准

### ✅ 必须通过
- [ ] `dotnet build` 或 Unity CLI 构建成功（无报错）
- [ ] GitHub Actions `unity-ci` workflow 运行成功
- [ ] 构建产物可启动（Windows .exe 不崩溃）
- [ ] 战棋格子显示 ≥ 1 张地图
- [ ] 角色可被选中并移动
- [ ] 回合制切换正确（我方→敌方→我方）
- [ ] 五行相克伤害修正 ±20% 内生效

### 🎯 理想通过
- [ ] 战斗评价 1-3 星计算正确
- [ ] 战前布阵界面可选择出场角色
```

## 🔄 每日开发流程

```bash
# 早上
git switch dev
git pull origin dev

# 编码...
git add .
git commit -m "feat: 实现XXX"
git push origin dev

# 晚上（如有 CI）
# GitHub Actions 自动构建 → 查看 Actions tab
```

## 🔄 发版流程

```bash
# 1. 更新版本号（在 Unity Project Settings）
# 2. 更新 CHANGELOG.md
git add .
git commit -m "chore: bump to v1.0.0"
git tag v1.0.0
git push origin main --tags

# 2. GitHub Actions 自动触发：
#    → Unity 构建（Windows/Linux/macOS）
#    → Steam Deploy（steamcmd 上传）
#    → GitHub Release（生成发布页）

# 3. 在 GitHub Release 页面确认产物
# 4. Steam Partner 后台设置"上线"
```
