**《苍穹战棋》| CangQiongWarChess**

## 一、必须安装（开发前准备）

### 1.1 Unity Hub + Unity Editor

```bash
# macOS 安装 Unity Hub（使用 brew）
brew install --cask unity-hub

# 或从官网下载：https://unity.com/download
# 下载后运行 Unity Hub
open -a "Unity Hub"
```

**Unity 版本要求**：
- **Unity Editor 2022.3 LTS**（推荐，稳定版）
- 安装模块：Windows Build Support / Linux Build Support / macOS Build Support

**安装路径建议**：
```
/Applications/Unity/2022.3.50f1/
```

### 1.2 Git + Git LFS

```bash
# macOS
brew install git git-lfs

# 初始化 LFS
git lfs install
git lfs track "*.png"
git lfs track "*.jpg"
git lfs track "*.wav"
git lfs track "*.ogg"
git lfs track "*.mp3"
```

### 1.3 GitHub CLI

```bash
brew install gh

# 登录 GitHub
gh auth login
# → HTTPS
# → Yes (登录 GitHub)
# → 浏览器授权
```

## 四、GitHub Secrets 配置（CI/CD 必须）

在 GitHub 仓库 Settings → Secrets and variables → Actions 中添加：

### Unity 激活（必须）

| Secret | 生成方式 | 说明 |
|--------|---------|------|
| `UNITY_EMAIL` | Unity 账号邮箱 | 用于 license 激活 |
| `UNITY_PASSWORD` | Unity 账号密码 | 同上 |
| `UNITY_LICENSE` | Base64 编码的 license 文件 | 见下文 |

**生成 Unity License（本地 Unity 已安装情况下）**：
```bash
# 在 Unity Editor 中：
# Edit → Project Settings → License Management → Activate New License
# → Manual activation → Copy license request code

# 在本机终端运行（需要 python3）：
python3 << 'EOF'
import base64
with open('/path/to/unity_license.ulf', 'rb') as f:
    encoded = base64.b64encode(f.read()).decode()
    print(encoded)
EOF
# 复制输出，粘贴为 GITHUB_SECRET UNITY_LICENSE
```

### Steam 部署（发布时配置）

| Secret | 说明 |
|--------|------|
| `STEAM_APP_ID` | Steam 游戏 App ID |
| `STEAM_USER` | Steam 用户名 |
| `STEAM_PASS` | Steam 密码 |
| `STEAM_AUTH` | Steam Guard 验证码 |
| `STEAM_MANIFEST` | VDF manifest 文件路径 |

## 五、Steam 开发者账号准备

### 5.1 注册 Steam Partner

```
1. 访问 https://partner.steamgames.com/
2. 使用 Steam 账号登录
3. 填写开发者协议
4. 等待审核（1-3 个工作日）
```

### 5.2 创建游戏 App

```
Steam Partner → 新建 App → 填写信息
App ID: 记录下来（稍后填入 STEAM_APP_ID）
App Type: Game
Developer: 你的名字/工作室名
```

### 5.3 创建 Depot

```
App 管理页面 → Depot → 新建 Depot
→ Windows Depot (depot ID 记录下来)
→ Linux Depot
→ macOS Depot
```

## 八、常见问题

### Q: Unity License 激活失败
**A**: 确保 `UNITY_EMAIL` 和 `UNITY_PASSWORD` 正确，且账号未过期。个人版 Unity 无 License 限制。

### Q: macOS 构建超时
**A**: macOS GitHub Actions runner 较慢，建议构建超时设置 `timeout-minutes: 120`。

### Q: Steam 上传失败
**A**: 检查 `STEAM_USER`/`STEAM_PASS` 是否正确，确保 Steam Guard 已关闭或 `STEAM_AUTH` 已配置。

### Q: LFS 文件未下载
**A**: 运行 `git lfs pull`，确保 `.gitattributes` 包含正确的 LFS 规则。
